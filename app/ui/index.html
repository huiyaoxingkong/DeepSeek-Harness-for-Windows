关于

        

          
DSH

          
DeepSeek Harness Desktop

          
基于 deepseek-ai/deepseek-harness 源码构建的 Windows 桌面封装。

          
核心可随时从 GitHub 官方源码更新；外壳 UI 为纯网页文件，可直接编辑
          ui/index.html、ui/style.css、ui/app.js 自定义界面。

DSH

        
欢迎使用 DeepSeek Harness

        
本地化运行的 AI Agent 工作台。核心为 deepseek-ai/deepseek-harness 官方开源项目，
           可随时从 GitHub 更新；外壳界面为本地网页，可自行定制。

      

      

        
▦

        
工作台

        
点击右上角「启动服务器」，dsh Web 界面将自动全窗口显示在应用内，可随时停止或重启服务器。

      

      

        
⚙

        
配置 API Key

        
在「设置」页填入 DeepSeek API Key。密钥以掩码显示、不可复制，点「更换」可随时输入新密钥。
           更多模型提供方（Anthropic / OpenAI / 自定义网关）可在 Web 界面「设置 → 模型」中配置。

      

      

        
◇

        
插件与核心更新

        
「插件」页可安装、卸载、启用、停用插件；「核心更新」页可一键从 GitHub 官方源码更新核心，
           更新流程自动完成依赖安装与构建。
